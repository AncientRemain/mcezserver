 Craftdock
A ***VIBE CODED***project designed to make hosting Minecraft servers right on your own machine completely painless.
The design is cool and super customizable. It might get updated whenever, who knows. If you run into big issues (like performance drops), just open an issue and I'll look into fixing it. All the source code is right inside the craftdock folder.
—————-Features———————
Multi-Server Hosting: Run multiple servers at the exact same time.
Web Panel: Clean dashboard featuring a built-in password security system.
Easy Networking:
Temporary domains & playit.gg integration
Automatic port forwarding via UPnP   
Connection & availability testing tools
Management & Automation:
Live server stats   
Task scheduling   
Automatic backups with easy restoration
Uploadable custom servers
Modding
Modrinth and CurseForge integration with togglable auto-updating   
Support for all popular server loaders (Fabric, Forge, NeoForge, etc.) plus Paper, Purpur, and more
Community:
Discord integration via webhooks
